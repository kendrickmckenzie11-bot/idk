Just A Rather Very Intelligent System
Jarvis online. Say "Hey Jarvis" or type a command below.
Idle Model: GPT-5 Nano

Commands

🌐 Browsing & Search

  • Open Google / Open YouTube
  • Search YouTube for lo-fi beats
  • Search Google for quantum computing
  • Open github.com

📁 File Operations

  • Open a file — triggers the file picker
  • Read file — reads the last opened file
  • Files are read locally; nothing is uploaded.

🖱 Mouse Control

  • Move mouse to the center
  • Click the mic button
  • Move mouse to 400 300
  • Simulated within the browser window only.

🤖 AI Conversation

  • Ask anything: "What's the weather like?"
  • Jarvis remembers the last few messages for context.
  • Powered by Puter.js — no API key required.

🎤 Voice

  • Click Listen or press Space to talk.
  • Say "Hey Jarvis" to wake it up.
  • Chrome/Edge recommended for best speech support.

⚠️ Browser Limits

For security, a web page cannot control the real OS mouse or open arbitrary files without your permission. Mouse control is simulated visually, and file access requires the system picker.
